# HeroCanvas in Spanish: the glossary

How HeroCanvas's own interface is translated (`src/i18n/es/*.json`, keyed by the English text; `t('…')` in the code).
Neutral Latin American Spanish, for any Spanish-speaking team: no voseo, no Spain-only words. Where a sentence
addresses the person, use `tú` (Elige, Abre, Pídele a tu agente); prefer an impersonal or infinitive form when it
reads as well (buttons: infinitive or noun, "Copiar", "Exportar PNG"). Short, plain, the same register as the English.
Sentence case, as in English (only the first word capitalized). Keep `{variables}`, product names (HeroCanvas, Figma,
Claude Code, GitHub, Supabase, iPhone, iPad, Android, iOS, Material, SF Symbols), code (`npm run …`, file names, prop
and token names), keyboard keys, and units as they are.
