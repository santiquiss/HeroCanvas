# Proposals

Your team's changes to the app, one folder each (`<yyyy-mm-slug>/`): what they add or replace, their versions and
their handoff. The Proposal panel creates them, or ask your agent for one (the `new-proposal` skill). Like `app/`,
this folder is yours: HeroCanvas's updates never touch it.

A proposal deleted once done (merged into the app, or dropped) leaves its code in `retired.json`
(`[{ "code": "PJ-3", "note": "Merged into Live in 0.4.0" }]`), so it's never given again.
